A static website, built to learn Azure

A simple site made with HTML and CSS, hosted on Azure Static Web Apps. I deployed it by hand in the Azure Portal first, then described the same infrastructure in Bicep to make it repeatable.

About the project

The goal is simple: go from a couple of files on my laptop to a live website in the cloud, and understand every step along the way.

⚡ Fast

Static files are served from a global CDN. No servers to manage and no build step.

🔒 Secure

HTTPS out of the box, plus security headers and a Content-Security-Policy in the config.

🔁 Repeatable

The infrastructure is described in Bicep: one file, one command, the same result every time.

The journey

Each step builds on the previous one. The last two are next on my list.

  1. Azure Portal

    Create the resource group and the Static Web App manually to understand how the pieces fit together.

  2. Bicep

    Describe the same infrastructure as code, delete everything, and redeploy with a single command.

  3. Next: CI/CD and Terraform

    Automate deployments with GitHub Actions, then rebuild the infrastructure in Terraform to compare.
